# 28_network_architecture

использовал образы almalinux вместо ubuntu-server, т.к. хотелось попробовать поработать на этом дистрибутиве.
настройку делал через shell провижинг в вагрантфайле, т.к. это позволило сэкономить время на отладке схемы путём исключения ошибок,
которые могли бы возникнуть при ручном вводе команд настраивающих ВМ. 

некоторые неточности в схеме исправлял, информацию об этом указал в комментариях в вагрантфайле.

план работ по выполнению дз
1. создать в вагрантфайле ВМ с конкретным образом, названием и нужным количеством CPU и RAM.
2. прописать все сетевые интерфейсы каждой ВМ в соответствии со схемой из ДЗ.
3. сделать shell провижинг, настраивающий сетевое взаимодействие всех ВМ согласно схемы из ДЗ.
4. поднять все ВМ.
5. сделать проверки и оформить документацию в файл info.
